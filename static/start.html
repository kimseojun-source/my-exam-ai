자주 묻는 질문

FOR'EST는 무엇을 하는 서비스야?
과목별 PDF 자료를 보며 설명을 확인하고, 문제와 복습으로 공부를 이어 가는 학습 웹앱이야.
지금 누구나 가입할 수 있어?
아직은 기존 사용자만 로그인할 수 있어. 신규 가입과 결제는 준비 중이야.
휴대폰과 태블릿에서도 사용할 수 있어?
웹브라우저에서 접속할 수 있고, 화면 크기에 맞춰 자료와 학습 화면이 배치돼.
이용 요금은 얼마야?
요금은 아직 확정되지 않았고 현재 신규 결제도 받지 않아.
